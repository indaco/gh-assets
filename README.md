# gh-assets

This repository contains image and video assets (e.g., GIFs, MP4s) used across various projects by [@indaco](https://github.com/indaco).

The purpose of this repo is to:

- Keep individual project repositories lightweight.
- Avoid bundling large binary files (GIFs, videos) in Go modules.
- Centralize and organize demo/showcase assets in one place.

## 📁 Project Assets

| Project    | Folder      | Description                                        |
| ---------- | ----------- | -------------------------------------------------- |
| [tempo]    | `/tempo`    | CLI for scaffolding and managing Templ components. |
| [goaster]  | `/goaster`  | Toast notification component for Templ apps.       |
| [tabber]   | `/tabber`   | Themeable and accessible tab component for Go.     |
| [gropdown] | `/gropdown` | Themeable and accessible dropdown for Go.          |
